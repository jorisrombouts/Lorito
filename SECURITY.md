# Security

Lorito has Accessibility access and hears your microphone, so a security problem matters. Please report one privately
through GitHub's "Report a vulnerability" button on the Security tab of this repository, not in a public issue.

Lorito makes no network connections except the one-time model download from Hugging Face on first launch. It does not
write what you say to disk; the last five dictations live in memory until you quit.
